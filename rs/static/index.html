Options

Private key

Stored as a plain file (secrets/private_key), so restarts resume on their own. Never shown again, only its address. The managed wallet becomes the key's address, the same on every chain.

Funding tokens

Per chain, the tokens swapped to buy what a pool on that chain needs when its allocation calls for tokens the wallet does not hold (largest balance first). Each chain starts with its USDC and USDT; an empty list turns funding off on that chain.

Chains & RPC

Where the app reads chain data and sends transactions. Defaults are dRPC's free public endpoints (3 requests per batch, about 40 requests a minute, reads grouped with Multicall3). Use your own endpoint for more speed or privacy; it is checked for the right chain before saving.

Interface

Safety

  • Depeg guard, 1h-median spot check, daily rebalance cap and gas check run before every action, on every chain.
  • Every transaction is simulated first; swaps only through the Solidly UI aggregator, capped vs the pool price.
  • Pause stops all actions immediately (persists across restarts).
