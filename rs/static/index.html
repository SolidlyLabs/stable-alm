Allocation of the managed value

Each enabled pool gets its % of everything managed (all positions + free tokens). Unallocated stays idle. A pool at 0% or disabled is withdrawn on the next cycle. If a pool's share needs tokens the wallet does not hold, they are bought with the funding tokens. APRs are estimates at each pool's target size (fees + emissions + bribes over the window, annualised, shared with the other in-range LPs); a pool at 0% shows the APR for a 10% slice. Raw figures, before the backtest's haircuts.

Estimated APR if deposited = (fees + emissions + bribes over the window, annualised) ÷ (average in-range TVL + your deposit), i.e. sharing like the average in-range LP. Data: Solidly UI pool list + data-processor hourly history. Raw figures, before the backtest's haircuts (fees ×0.82, SOLID ×0.5); the ladder's single ticks usually earn more than the average in-range LP, wide ranges less.
